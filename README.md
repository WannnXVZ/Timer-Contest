# RACE STOPWATCH

Stopwatch balapan modern untuk kompetisi robotika, line follower, atau perlombaan dua tim.

## Cara Penggunaan
1. Download atau clone repository ini.
2. Buka dan jalankan dengan browser kesayangan Anda dengan klik 2x pada file `index.html`.

## Info Tombol Keyboard (Hotkeys)
* **Spasi** : Mulai / Pause stopwatch (mode persiapan & balapan).
* **r** : Reset stopwatch ke waktu awal (saat kondisi pause).
* **a** : Mencatat waktu putaran (lap time) untuk Tim A.
* **b** : Mencatat waktu putaran (lap time) untuk Tim B.
* **o** : Mute / Unmute Sound FX (efek suara).
* **p** : Mute / Unmute Background Music (BGM).
* **F11** : Masuk / Keluar mode Fullscreen.
