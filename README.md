# RACE STOPWATCH

Stopwatch digital modern untuk mendukung pencatatan waktu dan pemantauan performa dalam kompetisi, perlombaan, serta pertandingan dua tim secara profesional.

## Cara Penggunaan
1. Download atau clone repository.
2. Buka folder project, lalu jalankan file index.html menggunakan browser.

## Info Tombol Keyboard (Hotkeys)
Spasi (Space): Memulai atau menjeda stopwatch (mode persiapan dan balapan).
R: Mengatur ulang stopwatch ke waktu awal (hanya saat dijeda).
A: Mencatat waktu putaran (lap time) Tim A.
B: Mencatat waktu putaran (lap time) Tim B.
O: Mengaktifkan atau menonaktifkan efek suara (Sound FX).
P: Mengaktifkan atau menonaktifkan musik latar (BGM).
F11: Mengaktifkan atau keluar dari mode layar penuh (Fullscreen).
